# Rebond

Site vitrine et réservation pour Rebond, boutique de smartphones reconditionnés à Sedan.

## Stack

- Vite + React + TypeScript
- Tailwind CSS 4 (`@tailwindcss/vite`)
- Sass (`sass-embedded`) pour les composants stylés en CSS Module
- Storybook (stories des composants de base + panneau Accessibility)
- ESLint

## Commandes

```bash
npm install
npm run dev             # serveur de développement
npm run build            # build de production
npm run lint              # ESLint
npm run storybook         # Storybook en local
npm run build-storybook   # build statique de Storybook
```
